# COCONUT WARS (COW) — 操作手冊

COCONUT WARS（COW）是 NTU CSIE Camp 大地遊戲的收尾戰鬥階段（15:10–15:45），透過本網頁程式即時輸入各隊指令、執行回合結算、並以視覺化地圖呈現戰況。

---

## 一、環境需求

| 項目 | 最低版本 |
| :--- | :--- |
| Python | 3.10+ |
| 瀏覽器 | Chrome / Firefox / Safari（現代版本） |
| 作業系統 | macOS / Linux / Windows（WSL） |

---

## 二、下載與啟動

### 1. 下載 repo

```bash
git clone <repo-url>
cd <repo>/www
```

### 2. 啟動伺服器

```bash
./start.sh           # 預設 port 5001
./start.sh 8080      # 自訂 port
```

> **Windows 用戶**：請在 WSL 或 Git Bash 執行，或直接執行：
> ```bash
> python -m venv venv && venv\Scripts\activate && pip install -r requirements.txt
> python app.py
> ```

第一次執行會自動建立虛擬環境並安裝相依套件。

### 3. 開啟介面

瀏覽器前往 `http://localhost:5001`（或指定的 port）。

## 三、賽前設定

首次進入會看到「賽前設定」畫面，共三個區塊：

### 3-1 基本設定

- **回合數**：填 1–5，遊戲規則為 3 回合。

## 四、主畫面操作

### 4-1 整體佈局

```
┌─────────────────────────────────────────────────────┐
│  Header：回合資訊 ｜ 上/下一回合 ｜ 真實模式 ｜ 執行  │
├──────────────────────────┬──────────────────────────┤
│                          │  指令輸入區              │
│  地圖（分析/真實模式）     │  ─────────────────────  │
│                          │  本回合指令記錄           │
├──────────────────────────┴──────────────────────────┤
│  椰子排行                                            │
└─────────────────────────────────────────────────────┘
```

### 4-2 輸入指令

1. 從左上「**輸入隊伍**」下拉選單選擇要輸入的隊伍。
2. 點擊指令模板按鈕可快速插入指令。
3. 在文字框輸入一至三條指令，每條可用**換行**或**空格**分隔：
   ```
   move(HK, NEU, 300)
   attack(ELF, ORC, 500, [-1])
   ```
4. 按「**發送**」提交，指令會即時標示有效 ✓ / 無效 ✗。
5. 提交後可點「**✏**」編輯或「**✕**」刪除單條指令。

### 4-3 指令格式

> 所有區域參數可用**英文代號**（不分大小寫）或**中文全名**。

---

#### move — 移動兵力

```
move(S, E, n)
```

| 參數 | 說明 |
| :--- | :--- |
| S | 出發區域（己方控制） |
| E | 目的區域（己方領地 / 中立小島 / 第2回合起可移至資源點） |
| n | 兵力數（正整數） |

```
move(HK, NEU, 300)
move(NEU, HK, 500)
```

> 舊版 `moving(...)` 語法仍相容。

---

#### attack — 進攻（含聯合進攻）

```
attack(S, E, n)             # 單獨進攻（等同於 [-1]）
attack(S, E, n, [-1])       # 明確標示單獨
attack(S, E, n, [P])        # 宣告與隊伍 P 聯合進攻
attack(S, E, n, [P1, P2])   # 宣告與多隊聯合進攻
```

| 參數 | 說明 |
| :--- | :--- |
| S | 出發區域（己方控制，且目標島上無己方駐兵） |
| E | 攻擊目標（他國領地或第 2 回合起的資源點；不可攻中立小島） |
| n | 派遣兵力數 |
| [P] | 聯合進攻夥伴列表；`[-1]` 或省略 = 單獨 |

```
attack(HK, ORC, 400, [-1])
attack(ELF, DV, 300, [2])
attack(ELF, DV, 300, [2, 3])
```

**⚠ 聯合進攻判定規則：**

1. **合法集合**：集合內所有成員**互相宣告**彼此為盟友，才構成合法 set。
2. **交疊衝突**：若兩個合法 set 有重疊成員，系統自動依下列優先順序解決：
   - ① 集合內**投入出兵數加總**較多者勝
   - ② 平手 → 集合內**隊伍數**較多者勝
   - ③ 平手 → 集合內所有成員**全場總兵力**較多者勝
   - ④ 平手 → 隨機
3. **敗者處理**：落敗集合的獨佔成員指令失效，兵力**原地遣返**。

**範例（5隊漏填4）：**
```
# 3隊宣告 [4,5]、4隊宣告 [3,5]、5隊宣告 [3]（忘記填4）
# → 合法 set: {3,4} 和 {3,5}（{4,5} 不合法，5未宣告4）
# → 出兵數相同 → 比全場兵力 → {3,4} 勝 → 5隊兵力返回
```

---

#### help / accept — 協防（盟友輸兵）

```
# 送出方：
help(S, E, n, P)

# 接收方：
accept(E, P)
```

| 參數 | 說明 |
| :--- | :--- |
| S | 己方出發區域 |
| E | 目標區域（P 的領地） |
| n | 派遣兵力數 |
| P | 接收方隊伍號 |

兩方**同回合**均提交且配對成功，兵力才會轉移。未配對的 help 指令兵力原地保留。

```
# 隊 1 送 300 兵到隊 2 的 ELF：
help(HK, ELF, 300, 2)   # 隊 1 提交

# 隊 2 接受：
accept(ELF, 1)           # 隊 2 提交
```

---

#### set — 管理員直接設定領地

```
set(zone, T:n, T:n, ...)   # 設定兵力
set(zone, K, T:n, ...)     # 設定強制佔領者 K + 兵力
set(zone)                   # 清空領地
```

僅限管理員帳號（ADMIN）使用。

```
set(HK, 1:500, 2:200)
set(ORC, 3, 3:800)
set(DV)
```

---

### 4-4 回合結算順序

1. **Phase 1**：所有移動同步執行（move / 配對 help+accept / attack 出兵）
2. **Phase 1.5**：300 最低防守規則 — 移動後兵力 1–299 的領地自動空島化
3. **Phase 2**：戰鬥結算（情境 A / 情境 B / 平手）
4. **Phase 3**：各領地產出椰子（按兵力比例分配，向上取百位）
5. **Phase 4**：中立小島兵力 × 1.5（向上取百位）
6. **Phase 4.5**：救濟補充 — 全場兵力 < 1000 的隊伍，中立小島補至 1000
7. **Phase 5**：資源點產出（第 2 回合起）

**戰鬥情境說明：**

| 情境 | 條件 | 守方存活兵力 |
| :--- | :--- | :--- |
| 情境 A（攻方勝） | 攻方總兵 > 守方總兵 | 存活 = 攻方總 − 最強守方；領頭隊保底 500 |
| 情境 B（守方勝） | 守方總兵 ≥ 攻方總兵 | 保底 50% + 戰俘加成 20%，向上取百位 |
| 平手 | 多方兵力並列最高互相消滅 | 空島 |

---

### 4-5 執行回合

全部隊伍輸入完畢後，按右上角「**▶ 開始執行**」。

- 系統同步執行所有指令並計算結算。
- 結果彈窗顯示本回合完整 log。
- **真實模式**下有動畫效果。

### 4-6 回合導航

| 按鈕 | 說明 |
| :--- | :--- |
| ↩ 上一回合 | 撤銷已執行的回合，回到上一個狀態 |
| ↪ 下一回合 | 使用「上一回合」後才可用，往前還原 |

### 4-7 顯示模式切換

點選右上角「**🗺 真實模式**」可切換：

- **分析模式**（預設）：表格式領地檢視，適合確認數值。
- **真實模式**：海洋地圖，執行時有動畫效果。

## 五、常見問題

**Q：指令顯示 ✗ 是什麼意思？**  
指令解析或驗證失敗，看錯誤提示。常見原因：兵力不足、出發區域不是己方控制、目標島上已有己方駐兵、第一回合攻資源點。

**Q：attack 顯示「聯盟衝突：被較強聯盟擊敗」？**  
你宣告的聯合進攻集合與另一個更強的合法集合有重疊成員，落敗方兵力自動遣返。重新與未被佔用的盟友組成集合。

**Q：help 指令沒有生效？**  
對方必須同回合提交對應的 `accept(E, 你的隊伍號)`，兩方配對才成功。

**Q：Port 被佔用無法啟動？**  
換用其他 port：`./start.sh 8080`

**Q：想重設遊戲怎麼辦？**  
按右上角「⚙ 重新設定」回到賽前設定畫面。
